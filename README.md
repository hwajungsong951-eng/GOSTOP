# 맞고 (GOSTOP)

오프라인으로 즐기는 2인 맞고 · 3인 고스톱 웹 게임.
설치 없이 브라우저에서 바로 실행되는 단일 HTML 게임입니다.

## 플레이 방법

- **온라인(권장)**: GitHub Pages 주소로 접속하면 폰·PC 어디서나 바로 플레이할 수 있습니다.
- **오프라인**: `index.html` 파일을 브라우저로 열어도 동작합니다.
- **앱처럼 설치**: 모바일 브라우저에서 "홈 화면에 추가"를 선택하면 PWA(전체 화면)로 실행됩니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 본체 (UI + 로직, 단일 파일) |
| `manifest.webmanifest` | PWA 설정 (앱 이름, 아이콘, 전체 화면) |
| `sw.js` | 오프라인 캐시 서비스 워커 |
| `RULES.md` | 맞고/고스톱 규칙 정리 |
| `CHECKLIST.md` | 개발 체크리스트 |

## 화투패

기본값은 **실사 화투패**입니다. Wikimedia Commons의 화투패 SVG 48장을 원본 그대로 사용합니다
(작가 Mliu92, CC BY-SA 4.0). 자세한 출처와 라이선스는 [CREDITS.md](CREDITS.md) 참고.

꾸미기 테마에서 다음 4가지를 고를 수 있습니다.

| 테마 | 설명 |
| --- | --- |
| 실사 화투패 | 실물 화투패 느낌의 원본 아트 (기본, 무료) |
| 전통 붉은 패 | 직접 그린 클래식 벡터 일러스트 (무료) |
| 청자 비취 패 | 비취색 테마 (30,000원 또는 업적 3개) |
| 금박 흑단 패 | 흑단·금박 테마 (100,000원 또는 업적 8개) |

실사 패 파일은 `cards/` 폴더에 카드 ID별로 들어 있습니다(`cards/01-bright.svg` 등).
이미지를 못 불러오면 자동으로 벡터 패가 표시됩니다.

## 등장인물 (타짜 오마주)

| 캐릭터 | 성향 | 난이도 |
| --- | --- | --- |
| 고광렬 | 판 위의 큰 어른 · 담담한 진검형 | 쉬움 |
| 정마담 | 판을 쥐는 마담 · 우아한 계산형 | 보통 |
| 짝귀 | 좁쌀 같은 승부사 · 잔머리 눈치형 | 보통 |
| 아귀 | 패를 삼키는 아귀 · 압박 강공형 | 어려움 |
| 평경장 | 좌판의 평경장 · 냉정한 계산형 | 어려움 |

이름은 영화 《타짜》에 대한 오마주이며, 모든 대사는 게임을 위해 새로 쓴 창작 대사입니다.

## 대사 직접 편집

설정 → **캐릭터 대사 편집**에서 5명 × 8가지 상황(판 시작·먹기·뻑·고·스톱·승리·패배·피박)의
대사를 직접 입력할 수 있습니다. 한 줄에 대사 하나씩 쓰면 되고, 비워 둔 칸은 기본 대사가 사용됩니다.
입력한 내용은 브라우저(localStorage)에만 저장되며 다음 대사부터 바로 적용됩니다.

## 로컬 실행

```powershell
npx serve .
# 또는
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속.
