# 맞고 (GOSTOP)

오프라인으로 즐기는 2인 맞고 · 3인 고스톱 웹 게임.
설치 없이 브라우저에서 바로 실행되는 단일 HTML 게임입니다.

## 플레이 방법

- **온라인(권장)**: GitHub Pages 주소로 접속하면 폰·PC 어디서나 바로 플레이할 수 있습니다.
- **오프라인**: `index.html` 파일을 브라우저로 열어도 동작합니다.
- **앱처럼 설치**: 모바일 브라우저에서 "홈 화면에 추가"를 선택하면 PWA(전체 화면)로 실행됩니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 본체 (UI + 로직, 단일 파일) |
| `manifest.webmanifest` | PWA 설정 (앱 이름, 아이콘, 전체 화면) |
| `sw.js` | 오프라인 캐시 서비스 워커 |
| `RULES.md` | 맞고/고스톱 규칙 정리 |
| `CHECKLIST.md` | 개발 체크리스트 |

## 화투패

카드 그림은 전통 화투 12개월 문양(송학·매조·벚꽃·흑싸리·난초·모란·홍싸리·공산·국화·단풍·오동·비)을
직접 그린 SVG로 렌더링합니다. 광·열끗·띠(홍단/청단/초단)·피·쌍피·국진·비광이 실제 패처럼 구분되고,
카드 뒷면도 전통 문양 패턴으로 그려집니다.

## 등장인물 (타짜 오마주)

| 캐릭터 | 성향 | 난이도 |
| --- | --- | --- |
| 고광렬 | 판 위의 큰 어른 · 담담한 진검형 | 쉬움 |
| 정마담 | 판을 쥐는 마담 · 우아한 계산형 | 보통 |
| 짝귀 | 좁쌀 같은 승부사 · 잔머리 눈치형 | 보통 |
| 아귀 | 패를 삼키는 아귀 · 압박 강공형 | 어려움 |
| 평경장 | 좌판의 평경장 · 냉정한 계산형 | 어려움 |

이름은 영화 《타짜》에 대한 오마주이며, 모든 대사는 게임을 위해 새로 쓴 창작 대사입니다.

## 로컬 실행

```powershell
npx serve .
# 또는
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속.
